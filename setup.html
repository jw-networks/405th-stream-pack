OBS Setup — Scenes & Hotkeys

If you move the folder later, run this page again from the new location.
Move plugin: obsproject.com/forum/resources/move.913. Install it before importing if you pick Move.

Then in OBS

  1. Settings → Video: Base (Canvas) Resolution 1920×1080.
  2. Menu Scene Collection → Import → pick the downloaded 405th-scenes.json, then switch to it.
  3. Camera links come from config.local.js → cameras. Each seat becomes its own CAM · … source, already placed in every scene. Changed a link? Right-click that CAM source → Refresh.
  4. OBS Multiview: View → Multiview (Windowed). For the most shots, go to Settings → General → Multiview → Layout → "Horizontal, Top 24 Scenes".
  5. Optional: Docks → Custom Browser Docks → add control.html for click-to-switch buttons (see README).

Hotkeys (built in)

NumLock must be on. Change any of them later in OBS → Settings → Hotkeys. Custom 2/3/4-up views (Multi-View A/B) are driven from the Director dock.
Studio Mode on: scene keys load Preview; Numpad + takes it live. Studio Mode off: scene keys cut straight to live.
